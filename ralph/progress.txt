[US-004] DONE — Resilient external API client core.
  - src/lib/resilient-client.ts: callWithRetry() generic wrapper around any
    async operation returning {status}. Retries on thrown errors and on
    429/5xx statuses with exponential backoff (baseDelayMs * 2^(attempt-1))
    + up to 25% jitter; sleep/random are injectable for deterministic tests.
    On exhaustion throws typed RetryExhaustedError (provider/operation/
    attempts/cause) and, if given an ErrorLogStore, writes one error_logs row.
  - src/lib/quota.ts: QuotaStore abstraction (getUsage/incrementUsage) with
    createDrizzleQuotaStore() backed by api_quota_usage (upsert via
    onConflictDoUpdate on provider+usageDate). checkQuota() throws typed
    QuotaExceededError when usedUnits+neededUnits exceeds a configurable
    dailyCap; recordUsage() increments the counter.
  - src/lib/error-log.ts: ErrorLogStore abstraction + createDrizzleErrorLogStore()
    backed by error_logs.
  - Store abstractions (QuotaStore/ErrorLogStore) let unit tests use
    in-memory fakes instead of needing a real database.
  - 14 new unit tests across resilient-client.test.ts and quota.test.ts
    (success path, 429 retry+succeed, 5xx retry+succeed, non-retryable 4xx
    short-circuits, exhausted retries throws+logs, thrown network errors
    retried+logged, typed error fields, quota under/at/over cap, zero-usage
    default, recordUsage increments + isolates by provider/date).
